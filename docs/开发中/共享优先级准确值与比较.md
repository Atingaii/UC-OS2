# 开发中：从共享存储的准确值走到优先级比较

这是 stage25 后的局部证明推进，不是完整 `OS_Sched`、最终 `GOOD_OS` 或 uC/OS-III 验收。上一轮的无条件连接见[前缀到切换](调度前缀到切换的物理连接.md)。正式函数证据和覆盖计数没有更新。

## 这一小步为什么必要

调度器接下来要判断：

```c
OSPrioHighRdy != OSPrioCur
```

要证明这次读取的比较结果，必须知道两个真实单元中的值。下面两句话不一样：

| 已知事实 | 能作出的判断 |
| --- | --- |
| 某地址存着类型正确的 UINT8 | 只能得到“存在某个字节”，不能断言它等于指定优先级 |
| 某地址唯一、完整地存着字节 `nc` | 能证明实际读取为 `nc`，再与选中的最高就绪优先级比较 |
| 抽象任务表记录当前任务的优先级为 `nc` | 单独不足以证明全局变量 `OSPrioCur` 的物理字节也是 `nc` |

旧前缀接口只保留额外单元的类型，因此不能凭空补出准确值。也不能把同一个完整字节既放在共享不变量中，又作为独占私有资源放进 `px`；那不是保存值，而是重复占有。

## 实际修改：保留到比较，归还时才忘记值

`V293OSSchedStoragePrefix.v` 将原有证明体提取为 retained 接口。增加的参数是一个准确的剩余资源断言 `kept`，只有两项必要约束：

- `GoodFrm kept`：它能作为真实调用／赋值的 frame 保留；
- `kept ==> V293_storage rest`：关闭共享不变量时，它能归还同一组有类型单元。

真实语句仍是调用 `OS_SchedNew` 后进行目标指针赋值。读取数组仍拆半、保留另一半、合并后归还。**并没有改 C、AST、共享单元列表或切换规则。** 原接口保留，作为 `kept = V293_storage rest` 的实例；原证明体不复制。

新的优先级实例在 `V293OSSchedStorageConnect.v` 中：

| 名称 | 含义 |
| --- | --- |
| `V293_priority_kept` | 完整的 `OSPrioCur` 准确字节，与其余存储分离组合 |
| `V293_priority_kept_erase` | 在字节范围内，将准确字节归还为同地址、同类型的存储单元 |
| `V293_OSSched_storage_priority_prefix` | 真实调用和赋值保留该准确字节；前后使用完全相同的共享布局 |
| `V293_storage_priority_comparison` | 从上述后置读取真实高优先级与当前优先级字节，证明实际比较的值和类型 |

精确 snapshot 使用同一状态上的普通合取 `//\\`，不是把同一个物理单元分成两份独占资源。`px` 外围只新增变量绑定，不新增该共享字节的私有副本。

比较结果为：两优先级相等时 `Int.zero`，不相等时 `Int.one`，类型为 `Tint32`。这一求值证明不需要任务表关系假设；它直接依赖物理字节和准确环境绑定。将结果与当前任务／最高就绪任务关系连接，仍须使用原有独立任务关系引理。

## 入口真的可满足，而不只是一个条件定理

`V293_storage_priority_entry_witness` 实际构造同一状态：

- 原有数组、真实 current／target 指针和唯一的抽象槽位；
- 独立块 `12`，按 UINT8 编码保存当前优先级，变量 `108` 绑定到该块；
- 准确字节放在共享入口 snapshot 内，而不是另加一项事后观察来代替保留证明；
- 两种任务模式：当前优先级 12 且就绪、当前优先级 4 且时间等待；最高就绪优先级均为 12；
- 任意事件表、时间和 continuation，空私有 frame／栈。

夹具中的 `idle_tid` 只是既有标识名字，不表示真实 idle task 可以等待。该见证没有构造完整函数环境，也不是初始化或可达性证明。它与上一轮 UINT32 计数器夹具分别构造；**尚未声称一个新入口同时具备准确优先级、计数器、两层 guard 及完整函数资源。**

## 下一步具体做什么

1. 将准确当前优先级与计数器放进同一个入口、同一布局；给出它的可满足见证。
2. 在真实 `if` 中接入本次比较：不相等时递增并走普通切换；相等时根据同一任务表完成抽象自调度并归还存储。
3. 再接两层 guard、临界区、函数环境和准确源码／port 对应。

目前只有“前缀保留准确字节”和“比较求值”接通，**不是新共享布局下的完整条件分支定理**。最终整核和 K1–K4 仍开放，uC/OS-III 尚未启动。
