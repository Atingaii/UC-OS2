# 第二十三阶段：比较、计数器与实际普通切换的纵向连接

## 固定对象与最小决策

仍验证固定 uC/OS-II V2.93.01，源码身份 `74390755cddc42a391055da46b744bbf32e77ba3dc025c2ae55b9441ba6170da`。`OS_Sched` 位于 `Source/os_core.c:1702–1732`，配置后函数体 SHA-256 为 `4bbf6819f5a458dfdadb30dbc8aeaad5156553b98f1b6466d4b89054cbd965e9`。冻结 C、配置、两类补丁、框架、策略与旧正式 JSON 均不因本轮修改。

stage22 已把含目标单元的同一个共享核心接回实际内部调用、目标赋值和两层 guard；stage21 已实例化真正普通 `switch_rule`。本轮不再增加脱离调用方的切换模型，而是在同一个 `V293_dispatch_inv` 下连接两者之间的真实比较与 32 位模递增，移除后半段 continuation／suffix oracle。

## 同一执行链与资源交接

新增 `V293OSSchedDispatchTail.v`。稳定接口 `V293_dispatch_prefix_change_switch` 顺序执行真实 `OS_SchedNew()` 调用、优先级数组读取、目标指针赋值、当前优先级比较、不相等时的计数器加一以及 `sprim (switch target)`。`V293_OSSched_guarded_dispatch_switch` 再接两层真实条件。它们仍是已列明规范化边界内的片段，不是完整 `OS_Sched` 的源代码对应定理。

`V293_dispatch_tail_split` 从调用／赋值的实际后置拆出切换资源。共享 snapshot 持有第一半当前指针；原 `CurLINV` 提供第二半，交给真正切换规则，而不是在局部 frame 中重复保留。空局部不变量剩余的 `Atrue` 被保留；多余的空 footprint 中断标志通过已有引理消除，没有任意丢弃空间资源。

`V293_dispatch_locals_good` 证明剩余局部 frame 的合法性；`V293_dispatch_tail_increment` 执行实际 `Int.add c Int.one`，允许最大值回绕；`V293_dispatch_tail_switch` 真正应用已有普通切换规则。后置是原线程恢复时的 `SWINVt`，不冻结切换前任务表、事件表、时间或目标。

| 路径 | 实际执行 | 后置动作 | 计数器 |
| --- | --- | --- | --- |
| 任一 guard 非零 | 保留完整原入口 | 仍为 `sched;;aop` | 不变 |
| 两 guard 为零、优先级相等 | 调用与目标赋值，不切换 | 仍为 `sched;;aop` | 不变 |
| 两 guard 为零、优先级不同 | 调用、赋值、递增、真正普通切换 | 原线程恢复时为 `aop` | 32 位模加一 |

不能将三个分支冒称已经具有统一的 `aop` 后置；未切换分支的抽象调度收尾仍开放。

## 完整入口的同状态见证

`V293OSSchedDispatchTailWitness.v` 新增 `V293_dispatch_full_precondition_witness`，对任意两个合法 guard 字节、任意计数器、事件表、时间和后续动作，构造包含真实 `sched;;aop` 的同一个完整入口状态。该状态同时拥有物理位图、优先级数组、当前优先级字节、计数器、目标、唯一四个抽象槽位以及同一个当前指针分出的两半权限。

同一个定理覆盖当前任务仍就绪／选回自己和当前任务正在时间等待／选择另一任务两种模式。见证固定空中断栈与空临界区栈，不是实际初始化、可达性、完整物理 `GoodI` 或合法自删除证明。

## 前瞻单因素协议与正向对照

本机 `audit/logs/stage23/PROTOCOL.txt` 在对应控制运行前记录因素及范围。第二半权限控制明确删除输入的保留半权限，不是删除输出义务；仅弱化输出不能检查输入资源是否必要。与该控制采用相同定义展开、但恢复 `CurLINV` 的正向基线，必须先通过核心、完整入口见证和固定独立探针。这样不把定义展开或语法脆弱性造成的失败误算为所有权检验成功。

| 控制 | 唯一逻辑变化 | 指定拒绝与必须先通过的步骤 |
| --- | --- | --- |
| `counter_post_two_only` | 只将递增根的返回计数器改为加二 | `V293_dispatch_tail_increment`；不记下游信用 |
| `resumed_pending_action_only` | 只将恢复后动作改回 `sched;;aop` | `V293_dispatch_tail_switch`；不记下游信用 |
| `branch_condition_inverted_only` | 只将分支后置的相等判定取反 | `V293_dispatch_change_switch`；不记下游信用 |
| `guard_false_premise_only` | 最终 guarded 根增加未用的 `False` 前提及其引入 | 核心、见证先编译，固定 guarded 接口拒绝 |
| `witness_pending_removed_only` | 只将实际构造状态的动作由 `sched;;aop` 改为 `aop` | 核心先编译，完整入口见证拒绝 |
| `reserved_half_neutralized_only` | 输入展开中只把 `CurLINV` 换成不含第二半指针的 `LINV ** Atrue` | `V293_dispatch_tail_split`；正向展开基线先通过，不记下游信用 |

独立探针字面固定实际资源、完整 pending 入口、比较与计数器、切换前后动作、分支和九个公开根的类型，不从候选断言生成预期。拒绝必须退出 1、包含 Coq `Error` 并落入准确文件和指定声明（含 `Proof` 至 `Qed`）的行范围；超时、无关声明、前置编译失败不计通过。

## 审稿式边界

- 本轮消除了比较／计数器与真正普通切换之间的顺序缺口，但最后一步仍是框架 SCAP 原语；`OSCtxSw` 的源码对应和 `OSPrioCur` 同步没有因此完成。
- 位图、优先级数组、当前优先级、计数器及两个条件字节目前作为该片段的独占局部 frame 保留，尚未被纳入完整物理共享不变量。不能推出其他任务运行时真实全局值保持不变。例如别的任务也可能增加 `OSCtxSwCtr`，所以局部恢复后置中的旧值加一不是完整内核跨切换后的全局计数器保证；接入其他任务前必须重组资源并调整该后置。
- 未切换分支的 `sched` 还没有消耗；临界区入口／出口、当前任务合法自删除后的特殊切换均开放。
- 完整入口可满足不等于可从实际初始化到达；九个辅助根不计新增函数覆盖。
- 物理 TCB／ECB／就绪结构、其他函数、完整函数环境与初始化、最终 `GOOD_OS` 及同程序 K1–K4 仍开放。uC/OS-III 未启动，总目标保持活动。
