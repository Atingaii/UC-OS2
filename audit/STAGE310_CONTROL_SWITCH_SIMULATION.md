# 第310步：原物理切换点的局部前向匹配

## 从哪里推进到哪里

第309步把固定控制前端的调度事件投影为原高层 `hswi_step`，实际前缀尚未执行物理切换。本步在已接受的 **normalized port 抽象边界** 内，连接原低层 `pswitch` 与同一目标的原高层切换，并复用旧框架的 `ProgSim` 构造器。没有新增一套低层语义，也没有修改 C、配置、AST 或旧框架。

- 生产接口：`certiucos/v293/proofs/V293InterruptControlSwitchSimulation.v`。
- 非空实例：`audit/probes/V293InterruptControlSwitchSimulationProbe.v`。
- 前瞻协议、成功/失败源码快照及实测：`audit/logs/stage310-control-switch-simulation/`。

## 三个生产结论

1. `V293_switch_owned_capture`：从切换不变量与三个真实控制字节的所有权，取得同一状态的控制捕获；不是由另给的控制观察假设替代内存。
2. **`V293_control_switch_forward`**：从目标指针读取、当前任务、最高就绪关系、代码项和所有权，构造成功的原物理存储、原 `lpstep` 与原 `hpstep`，并建立固定前端事件。输入不要求已经给出执行或成功存储。所有可能的低层一步后继必须等于构造的后继，而不只给出某个存在的执行；另排除输出步和 abort。后继保留控制捕获、目标物理指针、抽象当前任务及其他任务项/抽象键/指针字节外内存。
3. `V293_control_switch_progsim`：复用原 `V293_switch_progsim`，把上述一步匹配提升为原 `ProgSim`。**后继 `ProgSim` 仍是显式且独立的前提**；本步没有关闭无限后续执行，也没有证明直积状态框架的健全性。

控制字节 `r/n/l` 的范围、低层当前辅助状态 `IE=false`、共同指针类型、目标读取与原 `sd O next` 都是可见前提。本接口不偷偷推导任意就绪任务已在高层任务表中；完整程序必须自行建立这些不变量。

## 非空实际实例，不是互不相干的执行见证

`SMprepare` 从现有 `BXglobal true` 的 Exit 调用入口和实际非空堆出发，不输入执行轨迹。先运行完整 normalized Exit 调用，再运行真实优先级缓存拷贝，并把两段连接成同一全局轨迹 `SMsource`。原缓存为6，最高就绪优先级为4；不能跳过缓存同步而只检查任务指针。

`SMcompleted_match` 直接使用这条前缀的同一 `Ms` 调用新生产接口，取得物理切换及高层切换、后继控制捕获 `(1,0,0)`、物理 `OSTCBCur=Ready`、抽象 `curtid=Ready`、缓存4、所有低层后继唯一性及不 abort。

- Waiting 和 Ready 两个任务确实不同，两个任务表都非空；Ready 任务代码项、局部环境与辅助状态保持。
- `SMsaved_context` 单独核对切出任务的低/高层后继代码、局部 CPU 状态环境以及 `enabled::ci` 保存栈；低层 continuation 包含实际临界退出、返回和嵌套调用上下文。
- 实例覆盖任意初始 IE 布尔值、保存临界栈和 `clientst`，而不是仅一个空上下文值。
- 此实例入口仍为 Exit、深度1；保存中断上下文已经给定，**不声称本步从 `pint` 创建它或从初始化到达它**。高低任务代码的全面关系仍须放进后续原 `TaskSim` 不变量。

本步沿用已经存在的 `BXglobal true` normalized 程序，未把第309步停在缺失 raw port 的 `SXprogram` 偷换成已有 raw port 实现，也未声明整个 builder 程序已与该实例统一。源码级目标接受 normalized 切换/中断边界；汇编或硬件证明不是下一阶段的阻塞条件。

## 对抗性复核与边界

- 仅证明低层“存在一个好后继”不足：生产接口另量化所有后继，并显式排除输出和 abort。
- 物理目标与抽象目标分别执行可能不相干：本步使用同一 `next`、同一实际 `Ms/Mf`，并分别读回指针和 `curtid`；不把这一局部匹配推广为整个前缀的全交错模拟。
- 后置控制捕获不能意味着旧 `WFInt` 已经认识控制状态：本步没有改其类型或证明其迁移健全性。
- 用后继 `ProgSim` 假设闭合前继不能算整核完成：本步清楚保留 continuation 义务；实例没有给出无条件完整 `ProgSim`。
- 不把当前实例的非空任务和保存上下文提升为任意初始化可达性。

早期生产编译2次失败、实例编译11次失败均保留源码快照和日志。分离逻辑重排时，控制资源尾部 `Atrue` 与精确资源尾部 `Aemp` 不能仅靠排列相等；最终以空帧和原 `astar_mono` 显式证明蕴含，没有删除资源、不变量或修改旧定理。
