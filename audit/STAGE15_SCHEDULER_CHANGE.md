# 第十五阶段：优先级比较、模计数器与开放任务切换

## 对象、接口与边界

沿用固定 uC/OS-II V2.93.01、上游提交和两项已授权补丁；本轮不改 C、配置或通用框架。
源码身份仍为 `74390755cddc42a391055da46b744bbf32e77ba3dc025c2ae55b9441ba6170da`。
`OS_Sched` 定位为 `Source/os_core.c:1702–1732`，文件 SHA-256 为 `96eef5dc1a519887499cffd8f9a6c8873b96978ed9646c42e52eb6992422fea5`，配置后函数体 SHA-256 为 `4bbf6819f5a458dfdadb30dbc8aeaad5156553b98f1b6466d4b89054cbd965e9`。

整个调用方 AST 继续经过 GCC／Clang 双预处理、声明身份和精确形状检查。新增 Coq 发射逐字核对两个受限规范化：字节提升后 `a != b` 对应逻辑非相等；无 `volatile`、结果丢弃的 UINT32 后缀 `++` 对应一次模加一赋值。不是已验证 C 编译器，也不覆盖一般表达式中使用 `x++` 旧值的情形。

新增七根：

| 根 | 结论 |
| --- | --- |
| `V293_OSSched_counter_increment` | 真实赋值规则更新可写 32 位计数器；任意 `Int.int`，无不溢出前提 |
| `V293_OSSched_priority_comparison` | 同一前缀后置中的真实字节读取推出 `!=` 的 0／1 值和类型 |
| `V293_OSSched_tail_increment` | 计数器赋值接入原任务表和最高就绪指针状态 |
| `V293_OSSched_change_continuation` | 相同时不递增；不同时先递增，再保留切换后续义务 |
| `V293_OSSched_changed_prefix_continuation` | 接真实内部调用与指针赋值的顺序 Hoare |
| `V293_OSSched_guarded_changed_prefix` | 再接原两层条件，仅三条件同时成立时要求真实切换 continuation |
| `V293_OSSched_changed_precondition_witness` | 任意三个合法字节值及任意 32 位计数器，整个新前置在同一状态可满足 |

见证继续使用原位图／任务／指针表及当前任务资源；只增加独立只读当前优先级块 13 与可写计数器块 14，原 guard 块 11、12 也同时共存。新组合不是重建另一张抽象任务表。相同优先级路径的后置保留已经发生的最高就绪指针赋值，不能错误地声称回到整个初始前置。

见证证明的是本检查点空间前置可满足，不是完整内核运行态不变量。当前优先级只要求为合法字节，还没有证明它等于当前抽象 TCB 的优先级；当前 TCB 指针的权限和成员关系也尚不足以直接兑现 `switch_rule`。这些关系留在下一步，不因任意字节见证而声称已覆盖所有合法内核调度场景。

真正的上下文切换仍是显式 `suffix` 证明前提，不用普通 `OSCtxSw` 内部调用假设代替 `switch_rule`。临界区令牌、真实 TCB 字段／共享不变量、完整程序／初始化、`GOOD_OS` 及同程序 K1–K4 仍开放。函数六门覆盖不增加，uC/OS-III 未开始。

## 前瞻单因素控制协议

协议以 `scripts/v293-scheduler-change.py` 的固定接口、变异集合及指定义务写入后执行；不从待验定理读取或拼接期望类型。每次只改变表中因素，其余程序、证明、依赖、资源及接口不变。

| 单独变化 | 指定拒绝位置 |
| --- | --- |
| 仅反转优先级比较结论的 0／1 | `V293_OSSched_priority_comparison` |
| 仅去掉计数器单元的写权限 | `V293_OSSched_counter_increment` |
| 仅将递增定理的结果写成加二 | `V293_OSSched_counter_increment` |
| 仅交换同优先级／不同优先级的后置 | `V293_OSSched_change_continuation` |
| 仅给最终组合根增加“计数器不是最大值”前提 | 三个新模块含见证先编译，再由独立 `checked_guarded_change` 拒绝 |
| 仅给最终组合根增加 `False` 前提 | 三个新模块含见证先编译，再由独立 `checked_guarded_change` 拒绝 |

代码模块必须先成功；不能把前置模块错误冒充指定语义拒绝。代码／证明的同名 basename 保持不同命令身份，并拒绝重复标签。控制只证明指定敏感性，不声称穷尽所有错误。
