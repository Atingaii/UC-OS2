# 第二十二阶段：把共享目标接回真实调度前缀与两层条件

## 固定对象与本轮决策

仍验证固定 uC/OS-II V2.93.01。源码身份 `74390755cddc42a391055da46b744bbf32e77ba3dc025c2ae55b9441ba6170da`；`OS_Sched` 位于 `Source/os_core.c:1702–1732`，配置后函数体 SHA-256 `4bbf6819f5a458dfdadb30dbc8aeaad5156553b98f1b6466d4b89054cbd965e9`。冻结 C、配置、两类补丁、框架、策略和旧正式 JSON 不变。

stage20 前缀用不含目标的旧核心，stage21 切换用含目标的新核心；两者不能直接相加。本轮保留 stage21 的 `V293_dispatch_inv`，将同一份任务表与目标单元一起借给已证明的实际调用／赋值前缀，再归还同一个共享核心。没有另造内核或复制独占槽位。

## 真实纵向连接

新入口 `V293_dispatch_entry` 观察同一个当前任务与任务表／事件表／时间；目标单元仍在共享不变量中，入口允许任意类型正确的空指针或真实指针，不预设正确选择结果。打开／关闭接口使用四个槽位的同状态取值唯一性。

全局目标名称和块地址通过同一个全局环境对应；两个转换引理保留 bindings，只转换实际单元表达式。`V293_OSSched_dispatch_prefix` 由真实内部调用、优先级读取与目标赋值的已有资源证明导出。实际外层 `RI` 是含目标的完整不变量；被调契约仅拥有打开后的空核心，避免重复占有已借出的资源。后置保留原任务表／事件表／时间并观察实际选中的最高就绪目标。没有 suffix oracle 或额外 `False` 前提。

`V293_OSSched_guarded_dispatch_prefix` 接入两层真实字节条件：只有两个字节都是零才执行前缀，其余分支保留完整原入口，包括旧目标单元。该接口对任意合法字节、动作与动态栈参数化；未包含比较、计数器或实际切换。

完整前缀入口见证复用 stage20 同一状态，将同一个目标单元移动进新核心，不重造另一份 fixture；覆盖当前 ready／目标相同和当前时间等待／目标不同两种模式，事件表及时间任意。它只有 `spec_done None`、`Aemp` 和空栈实例；不是含两层 guard 的完整入口可满足性、待执行调度动作见证、初始化或可达性证明。

## 前瞻协议与指定控制

本机 `audit/logs/stage22/PROTOCOL.txt` 在新负控运行前记录并澄清六项单因素控制。最初拟改事件值改为返回时间加一，避免无用参数的类型推断干扰；额外 `False` 只加到无下游调用者的 guarded 根；见证只改变复用 fixture 的时间，不声称移除槽位。各项澄清先于控制运行，不回写旧证据。

| 控制 | 唯一逻辑变化 | 指定拒绝及前置 |
| --- | --- | --- |
| `post_time_changed_only` | 仅返回时间变成原值加一 | 前缀根拒绝，不计下游 |
| `callee_owns_dispatch_core_only` | 仅前缀声明内的两个被调规格选择器占有完整核心 | 前缀根拒绝，不计下游 |
| `target_returned_old_only` | 仅归还的目标改成当前任务，而非实际选中者 | 前缀根拒绝，不计下游 |
| `guard_false_premise_added_only` | 仅 guarded 根增加未用的 `False` 及引入 | 两个模块先编译，固定 guarded 接口拒绝 |
| `witness_stale_time_only` | 仅实际复用的完整 fixture 时间改成加一 | 核心编译，新完整前缀入口见证拒绝 |
| `disabled_guard_post_changed_only` | 仅禁用分支后置从原入口改成执行后 | 前缀根已编译，guarded 根拒绝 |

独立探针字面固定四槽位、类型正确的完整目标、完整不变量结构、无外置目标的入口、归还目标的后置、两层 guard、两个模式的完整前缀入口及稳定根类型；不从候选类型生成预期。拒绝必须退出码为 1、含 `Error`、命中准确文件与声明行范围。探针声明带 `let`，行范围按真正的 Coq 语句结束点识别，不把局部 `:=` 或限定名称中的点当作结束。前置失败、超时或无关声明拒绝不计通过。

## 审稿式边界

- 本轮消除了前缀与实际普通切换之间的共享核心不一致，但尚未通过比较／计数器把二者顺序连接。
- 前缀与 guard 是冻结函数的真实片段，不是整个 `OS_Sched`。六门覆盖不增加。
- 入口没有要求目标已正确；后置的目标来自真实写入。完整前缀见证不能为未构造的完整 guarded 状态或 pending 动作背书。
- `OSCtxSw` 对应、`OSPrioCur` 同步、合法自删除切换、物理 TCB／ECB／就绪结构、临界区、函数环境与初始化仍开放。
- 最终 `GOOD_OS` 和同程序 K1–K4 未完成；uC/OS-III 未启动，总目标继续活动。
