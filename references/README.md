# 随交接保留的参考资料

本目录保存原交接包中的论文、源码压缩包、框架归档和工作记录。它们用于阅读、核对和理解背景，**不属于活动验证代码或构建依赖**。本次不改写原始资料内容。

| 资料 | 用途 |
| --- | --- |
| `CoqIMP.pdf`、`许峰唯.pdf` | 理解验证框架与既有研究 |
| `coqimp-8.18.tgz` | 框架源码参考归档 |
| 两份内核源码 ZIP | 对照版本行为；不能未经身份校验替代主线源码 |
| `uCOS2发现的4类bug.md` | 原始反例说明 |
| `ucos293-证明.md` | 历史工作记录，包含不同阶段的信息 |
| `项目交接说明.md` | 随项目单独提供的原始交接说明；副本保留原内容，仅清理行尾空白及文件尾多余空行 |

工作记录中的函数数目、检查通过或后续提交，必须由对应代码和实际命令重新核实。根目录 `start-prompt.md` 与 `work-prompt.md` 同样按原交接保存，不代表当前可直接执行的工作计划。

当前项目范围、进度和材料错位说明见根目录的中文文档。最终工程不得依赖本目录，即使将其整体移除，活动代码与构建也不应引用其中内容。
